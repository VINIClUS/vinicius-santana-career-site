# Recruiter and Staff Engineer Review Notes

This document records the intent behind the landing page revision.

## Positioning

The page now leads with a concrete role fit: Data Engineering, Software Engineering and platform-adjacent operations. It avoids broad claims such as "senior", "expert" or template language unless supported by project details.

## Hero hierarchy

The hero prioritizes three questions a recruiter or technical evaluator needs answered quickly:

1. What role is this person targeting?
2. What kind of systems has he worked on?
3. Is he available and easy to contact?

## Project credibility

Project cards were rewritten to include technical constraints and proof points:

- CnesData: Firebird, Parquet, BigQuery, PostgreSQL, explicit source provenance, audit rules and tests.
- e-SUS PEC Bootstrap: provisioning, TLS/OAuth, backups, monitoring and runbooks.
- AquaFarm API: asynchronous sensor ingestion, PostgreSQL persistence and automated tests.

## Accessibility and performance

The implementation includes a skip link, semantic sections, keyboard-friendly navigation, high contrast, visible focus states, reduced-motion support and optimized responsive photos in AVIF/WebP/JPG.
